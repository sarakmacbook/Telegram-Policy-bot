Scanning & actions

Local phrase checks create review cases; image content is not automatically classified.

Queue all images for review

Send every image a moderator can see to the review queue. Image pixels are not automatically classified; this can create many cases.

Auto-hide text-flagged messages

Delete a message after a text phrase check flags it. The saved case remains available for review and restoration.

Requires Telegram delete-message permission. False positives are possible.
Auto-hide visual-review media

Only applies when image review is enabled. This removes every queued image before a person sees it.

Use with care — this is not an image classifier.
Post a notice when a message is auto-hidden

Tell the group a message was removed and a moderator will review it.

HOW REVIEW WORKS

A human stays in control.

01

Receive only what Telegram sends the bot. Group visibility requires correct bot permissions and privacy settings. Secret Chats cannot be monitored.

02

Run local phrase checks. Only potential matches are retained. Image content is not automatically interpreted; optionally queue media for people.

03

Review, then decide. Telegram does not let a bot undelete an original message. Restore posts a saved copy; author, timestamp, and original message ID are not recreated.
